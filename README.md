# TETRIS

Classic falling-blocks game. Source is in `docs/` (static site).

## Play URL

Once GitHub Pages is on: **https://raxus86.github.io/tetris/**

### Turn on Pages (once)

1. Open [Pages settings](https://github.com/Raxus86/tetris/settings/pages)
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch **main**, folder **/docs**
4. Save

The game is then at the URL above. On a phone/tablet, open it in Chrome → **⋮ → Install app**.

Guideline rules, hold, next queue, ghost piece. Original overworld-style chiptune (not Nintendo audio).
